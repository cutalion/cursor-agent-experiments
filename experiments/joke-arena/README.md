# Experiment: joke-arena

## Run Configuration
- **Models**: auto, claude-4.6-sonnet-medium-thinking, claude-opus-4-7-high, composer-2, gemini-3.1-pro, gpt-5.5-high
- **Base Branch**: main
- **Prefix**: exp
- **Plan File**: experiments/joke-arena/plan.md

## Goal
Build a production-ready Ruby on Rails web app for comparing jokes generated by configurable RubyLLM models. The app should include a prompt entry page, a joke comparison flow, voting, score updates, and a leaderboard.

## Mockups
The experiment is designed to accept three future screenshots:

- `mockups/main.png` for the prompt entry page
- `mockups/compare.png` for the joke comparison page
- `mockups/leaderboard.png` for the leaderboard page

If these PNGs are present when an agent implements the app, the UI should follow them. If they are not present, the agent should build a clean, responsive, accessible interface that can later be adjusted to match them.

## Expected Implementation
Agents should create the Rails application inside `experiments/joke-arena/app` unless the experiment runner explicitly requires implementation files at the repository root.

## Evaluation Focus
- Rails, SQLite, Hotwire/Turbo, Stimulus, ERB, CSS, YAML, and tests
- Config-driven model setup
- Correct RubyLLM integration
- No real LLM API calls in tests
- Transactionally correct voting and scoring
- Reproducible setup and a passing test suite
